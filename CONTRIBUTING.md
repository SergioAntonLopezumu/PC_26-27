# Contribuir al proyecto

Gracias por colaborar con este proyecto.

## Flujo de trabajo

1. Haz fork o clona el repositorio.
2. Crea una rama para tu cambio.
3. Implementa la mejora o corrección.
4. Ejecuta las pruebas necesarias.
5. Abre un Pull Request usando la plantilla.
6. Espera revisión y aprobación.

## Ramas

Usa nombres descriptivos:

- `feat/...` para nuevas funcionalidades
- `fix/...` para correcciones
- `docs/...` para documentación
- `chore/...` para tareas de mantenimiento

## Validación

Antes de abrir un PR, asegúrate de ejecutar:

```bash
mvn test
